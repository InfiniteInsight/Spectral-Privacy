## Key Patterns Identified

### Privacy Email Patterns

1. **Standard privacy@domain.com** - Most common (32 brokers)
   - Recommended for companies not yet using this pattern
   - Examples: privacy@hubspot.com, privacy@clearbit.com, privacy@salesforce.com

2. **Support/Customer Care** - Common alternative (8 brokers)
   - Examples: support@truepeoplesearch.com, customercare@mylife.com
   - Often dual-purpose for privacy and general support

3. **Specific Opt-Out Addresses** - Best practice (6 brokers)
   - Examples: optout@spydialer.com, removals@radaris.com, opt-out@peoplelooker.com
   - Clearer intent and routing

4. **Company-Specific** - Data aggregators (5 brokers)
   - Examples: consumeradvo@acxiom.com, gdprsupport@adobe.com
   - Often have specialized privacy teams

### Web Form Usage

**Why brokers use forms instead of email:**
- Verification requirements (confirm identity)
- Automated processing systems
- CCPA compliance tracking
- Prevents spam/bulk requests
- User must find their specific listing

**Notable form-only brokers:**
- Major tech platforms: Google, Meta, Microsoft, Amazon
- Ad tech: Criteo, Quantcast, Taboola, Outbrain
- People search: Nuwber, CheckPeople, PeopleSmart

### Placeholder {user_email} Pattern

**14 brokers use {user_email} placeholder:**
- Indicates form-based submission where user enters their own email
- Used for verification/confirmation emails
- Examples: BeenVerified, Intelius, Spokeo, Radaris, MyLife
- **Note:** These should be updated with actual contact emails where available
